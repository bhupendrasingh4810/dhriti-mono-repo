# Security and Compliance Summary

Evidence in the repository includes API authentication and authorization guards, tenant and organization context controls, Helmet, credentialed CORS from configuration, validation that rejects unknown fields, bcrypt password hashing, and production validation for `SECRETS_ENCRYPTION_KEY`.

Shared UI changes are required by repository guidance to use theme tokens and preserve accessibility defaults such as keyboard focus, labels, contrast, and semantic structure. The repository does not establish formal compliance certification, data-processing terms, data residency, retention, or client-side token storage policy.
